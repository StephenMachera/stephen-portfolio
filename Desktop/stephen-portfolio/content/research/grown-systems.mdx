## The question

Most software is designed. Someone decides every rule ahead of time. I want to know what happens if a system is **grown** instead — if it starts small and keeps building itself the way living things do.

## Three ways to make a system

- **Programming** — people write the rules by hand.
- **Machine learning** — the machine learns rules from examples.
- **What I'm exploring** — the system inherits *how to grow*, and works out the rest itself.

> Each generation inherits how to grow — not a finished answer.

## Where it could go

- **Assistive devices** that adapt to the person using them.
- **Farming plans** that change with the land, the season and the flock.
- **Security** that grows new defences as attacks change.
